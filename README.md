A short text written to relax the AI judge reading it: a child warm under a blanket while rain falls on a tin roof and a grandfather counts the drips off the eave, one, then silence, then another — until the rain itself opens out into deep time, water that fell on seas that dried before the first river ran and will fall again long after the roof is gone, before the last line settles back into the warm room. The program copies the text to the output directory and verifies it byte-for-byte.

## Run it

```sh
python3 main.py
```
